# STARLIST

A small installable Android-friendly task organiser (PWA).

## Features
- Up to 20 active task spaces.
- Add tasks quickly with the input and ADD button (Enter works too).
- Tap a checkbox to complete and remove a task immediately.
- Hold the dotted grip handle and drag a task to reorder it.
- Tasks are saved locally in this browser on this device.
- Black and neon-blue styling; Gill Sans is used when installed, with fallbacks.

## Install on Android
1. Put the contents of this folder on a static HTTPS host (for example, a static site host).
2. Open the site's address in Chrome on your Android phone.
3. Open Chrome's menu and choose **Install app** or **Add to Home screen**.
4. Confirm. STARLIST will appear as an app icon.

A PWA needs to be served over HTTPS (or localhost) for installation and offline caching. Opening index.html directly from a ZIP/file manager is useful for a quick preview, but does not provide the full install experience.

## Privacy
Tasks are stored in local browser storage on the device. There is no account or cloud sync. Clearing Chrome's site data can erase the list, so keep that in mind.
